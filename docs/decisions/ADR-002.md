# ADR-002 — Default assistant rather than boot-start microphone shortcut
**Decision:** Prefer selected `VoiceInteractionService` for persistent interaction; use boot receivers only for appropriate non-mic setup and reconciliation. **Why:** Android 14 restrictions on microphone FGS launched from boot and system-managed assistant lifecycle. **Limit:** Device-specific feasibility to be verified; no guarantee before first unlock. **Status:** Proposed; SPIKE required.
